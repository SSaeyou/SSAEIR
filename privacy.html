개인정보 안내

현재 방문 통계는 비활성 상태입니다. 활성화하면 Cloudflare Web Analytics로 기본 방문 규모와 유입 경로를 확인합니다.

작성 내용

참고사진, 파일명, 자유 메모, 성별, 선택한 헤어 요청값과 생성된 요청문은 현재 브라우저에서 처리하며 통계 서비스에 보내지 않습니다. 저장하는 결과 이미지에도 참고사진을 넣지 않습니다.

방문 통계

통계를 활성화하면 Cloudflare의 스크립트를 불러와 방문 횟수, 페이지 조회, 유입 사이트를 측정합니다. 스크립트와 통계 신호를 받는 과정에서 접속 정보가 Cloudflare에 전달됩니다. Cloudflare는 이 서비스가 쿠키·브라우저 저장소·개인 식별용 지문을 사용하지 않는다고 설명합니다.

작성 내용은 사이트 주소에 붙이지 않습니다. Cloudflare는 URL의 검색어를 통계에 기록하지 않는다고 안내합니다. 자세한 처리 방식은 Cloudflare Web Analytics 안내를 참고해 주세요.

통계 확인과 문의

통계는 사이트에 공개하지 않으며 운영자만 자신의 Cloudflare 계정에서 확인합니다. 방문 횟수는 실제 사람 수와 다르고 재방문이 포함될 수 있습니다. 브라우저의 추적 차단 기능으로 일부 방문이 빠질 수 있습니다.
